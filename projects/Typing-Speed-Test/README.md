# Typing Speed Test

A small typing speed test built with plain HTML, CSS and JavaScript (no libraries).

## Features
- 15, 30 and 60 second tests with fresh random words every run
- Live words per minute, accuracy and countdown
- Correct and incorrect characters highlighted as you type
- Personal best saved per test length (localStorage)
- Keyboard friendly: press `Esc` to restart; responsive layout; respects reduced-motion

## How WPM is calculated
Only correctly typed characters count. `WPM = (correct characters / 5) / minutes`.

## Run it
Open `index.html` in any browser.
